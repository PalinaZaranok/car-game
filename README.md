# Car-game
## 1. Протокол: сообщения от STM32 к ПК

### Формат
```
S<steer>,F<forward>,B<backward>\n
```
### Поля
| Поле | Диапазон | Источник | Смысл 

- `steer` | 0…1023 | Аналоговый вход A0 (потенциометр) | Положение руля: 0 — влево, 512 — прямо, 1023 — вправо 
- `forward` | 0 или 1 | Цифровой вход D2 (кнопка «газ») | 1 — кнопка нажата |
- `backward` | 0 или 1 | Цифровой вход D3 (кнопка «тормоз/назад») | 1 — кнопка нажата |

### Пример строки
```
S512,F0,B0
S847,F1,B0
S203,F0,B1
```
### Частота отправки
Не менее **30 Гц** (в скетче — `delay(10)`, то есть ~100 Гц с запасом).

## 2. Протокол: сообщения от ПК к STM32

### Формат
Один символ команды + `\n`:

| Команда | Событие в игре | Реакция 

- `C` | Собрана монета | LED1 (D13) горит 200 мс + короткий писк (100 мс, 2000 Гц) 
- `X` | Столкновение с пешеходом | LED2 (D12) горит 500 мс + длинный писк (300 мс, 2000 Гц)

### Работа
- **STM32 → ПК:** поток строк `S…,F…,B…`. Поток чтения накапливает байты в буфере, выделяет строки по `\n`, парсит три числа и записывает их в `CarState`.
- **Игровой цикл** (JavaFX `AnimationTimer`, ~60 FPS) читает `CarState` и двигает машину.
- **ПК → STM32:** при столкновении игровой цикл вызывает `eventSink.accept('C')` или `'X'` → `SerialReader.sendEvent()` → байт уходит в порт → Arduino включает LED/зуммер.
