# Car Game
## 1. Протокол: сообщения от STM32 к ПК

### Формат
```
S<steer>,F<forward>,B<backward>\n
```
### Поля
| Поле | Диапазон | Источник | Смысл 

- `steer` | 0…1023 | Аналоговый вход A0 (потенциометр) | Положение руля: 0 — влево, 512 — прямо, 1023 — вправо 
- `forward` | 0 или 1 | Цифровой вход D2 (кнопка «Вперёд») | 1 — кнопка нажата |
- `backward` | 0 или 1 | Цифровой вход D3 (кнопка «Назад») | 1 — кнопка нажата |

### Пример строки
```
S512,F0,B0
S847,F1,B0
S203,F0,B1
```

## 2. Протокол: сообщения от ПК к STM32

### Формат
Один символ команды + `\n`:

| Команда | Событие в игре | Реакция 

- `C` | Собрана монета | LED1 (D13) горит 200 мс + короткий писк (100 мс, 2000 Гц) 
- `X` | Столкновение с пешеходом | LED2 (D12) горит 500 мс + длинный писк (300 мс, 2000 Гц)
